# Changelog

All notable changes to ImageFit are documented here. Desktop release notes are also generated from merged pull requests and their labels.

## Unreleased

### Added

- Desktop hardware capability reporting, native output folder selection, and OS media opening.
- Windows NSIS installer, file associations, GitHub Release update checks, and install-and-restart action.
- Video export choices for H.264, H.265/HEVC, AV1, VP8, VP9, MPEG-4 Part 2, ProRes, DNxHD, MJPEG, and Theora.

### Changed

- The website remains browser-only: desktop controls and native integrations activate only in Electron.

## 0.1.0

### Added

- Initial ImageFit web and desktop release workflow.
